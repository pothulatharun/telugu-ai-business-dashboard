FAQ

Questions, answered

Can the assistant speak Telugu and English?

The intended product supports a Telugu-English conversational experience. Actual quality depends on the configured speech and voice services.

Can each business use its own Google Form?

The existing dashboard and backend support business-specific settings. The calling workflow must use those settings when it is integrated.

Does uploading a CSV start calls automatically?

Not currently. The dashboard's CSV feature previews rows only. Uploading leads to a backend and starting campaigns are separate features still to be built.

Can I send a form link through WhatsApp?

That requires the WhatsApp integration, applicable messaging permissions and an approved message template where required. Only send messages with appropriate consent.
